# Adnane SIDI-AMADOU — Portfolio V2

Un portfolio d'ingénieur Full Stack moderne, performant et immersif, conçu avec **Next.js 16** et **Tailwind CSS v4**.

## 🚀 Stack Technique

- **Framework** : [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/) (Ultra-performant, configuration simplifiée)
- **Langage** : TypeScript (Strict Mode)
- **Animations** : Framer Motion (Effets 3D Tilt, Reveal animations)
- **Icônes** : Lucide React
- **Gestion d'état** : React Context (Multilingue)
- **Contact** : Intégration Formspree (Envoi d'emails réel)

## ✨ Fonctionnalités Clés

- **Multilingue (FR/EN)** : Détection automatique de la langue du navigateur et mémorisation du choix utilisateur.
- **Design Immersif** : 
  - Effet 3D Tilt sur les cartes de projets.
  - Layout alterné (Visual Left/Right) pour les projets phares.
  - Mode sombre (Dark Mode) natif haute performance.
- **Architecture Modulaire** : Chaque section est un composant indépendant, facilité par une source de données centrale (`lib/data.ts`).
- **Optimisé SEO** : Balisage sémantique HTML5 et métadonnées dynamiques.
- **Formulaire de Contact** : Fonctionnel avec gestion des états d'envoi et validation.

## 🛠️ Installation et Développement

1.  **Cloner le dépôt** :
    ```bash
    git clone https://github.com/AdnaneAD1/portfolio-adnane.git
    cd portfolio-adnane
    ```

2.  **Installer les dépendances** :
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```

4.  **Build de production** :
    ```bash
    npm run build
    ```

## 📂 Structure du Projet

- `/app` : Pages et layout principal.
- `/components` : Composants UI et sections du portfolio.
- `/context` : Gestion du contexte global (Langue).
- `/lib` : Données du portfolio (`data.ts`) et utilitaires.
- `/public` : Assets statiques (Favicon, CV, images).
